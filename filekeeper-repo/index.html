Python 3, standard library only

Manage text files from one numbered menu.

Filekeeper is a small Python program that creates, reads, updates and deletes text files from the terminal. Pick a number, answer the prompts, and it does the rest.

    Five menu options

    Each one asks for what it needs, one prompt at a time, then goes back to the menu.

    1. 1

      Create a file

      Asks for a file name. If a file with that name already exists it stops and tells you, so nothing gets overwritten. Otherwise it asks for the text and writes it.

    2. 2

      Read a file

      Asks for a file name and prints what is inside. If the file does not exist, it says so.

    3. 3

      Update a file

      Rename the file, append a line to the end, or overwrite the contents. A rename is refused when the new name is already taken.

    4. 4

      Delete a file

      Removes the file by name. There is no confirmation prompt, so check the name before you press Enter.

    5. 5

      Exit

      Ends the menu loop and closes the program.

    Run it yourself

    Files are created in the folder you start the program from.

    1. Save the source below as file_manager.py.

    2. Open a terminal in that folder and start it.

      python file_manager.py

    3. On some systems the command is python3.

      python3 file_manager.py

    The whole program

    Four functions, one unused stub and one menu loop, 104 lines in total.

    from pathlib import Path
import os
def createfile():
    try:
        filename = input("Enter the filename: ")
        path  = Path(filename)
        if not path.exists():
            with open(filename, "w") as fs:
                data = input("Enter the data to be written in the file")
                fs.write(data)
        else:
            print("File already exists")
    except Exception as err:
        print(f"An error has occured {err}")

def readfile():
    try:
        filename = input("Enter the filename: ")
        path = Path(filename)
        if path.exists():
            with open (filename,"r") as fs:
                content = fs.read()
                print(f"Your content is \n {content}")
        else:
            print("No such file exists")
    except Exception as err:
        print(f"An error has occured {err}")

def updatefile():
    try:
        filename = input("Name the file to update ")
        path = Path(filename)

        if path.exists():
            print("To Rename the file press 1:")
            print("To Append the file press 2:")
            print("To Overwrite the file press 3:")
            choice2 = int(input("Enter the choice"))
            if choice2 == 1:
                newname = input("Enter the New File Name: ")
                new_path = Path(newname)
                if not new_path.exists():
                    path.rename(new_path)
                    print("Renamed Successfuly")
                else:
                    print("The File already exists")
            elif choice2 == 2:
                with open(filename, "a") as fs:
                    data = input("Enter the data to be appended: ")
                    fs.write("\n"+ data)
                print("Success")
            elif choice2 == 3:
                with open(filename, "w") as fs:
                    data = input("Enter the data to be appended: ")
                    fs.write("\n"+data)
                print("Success")
    except Exception as err:
        print(f"An error has occured {err}")



def deletefile():
    try:
        filename = input("Enter the filename: ")
        path =  Path(filename)
        if path.exists():
            path.unlink()
            print("Success")
        else:
            print("No such file")
    except Exception as err:
        print(f"An error has occured {err}")

def exitfile():
    return

while True:
    print("\n===== FILE MANAGEMENT SYSTEM =====")
    print("1. Create a file")
    print("2. Read a file")
    print("3. Update a file")
    print("4. Delete a file")
    print("5. Exit")

    choice = input("Enter your choice: ")

    if choice == "1":
        createfile()

    elif choice == "2":
        readfile()

    elif choice == "3":
        updatefile()

    elif choice == "4":
        deletefile()

    elif choice == "5":
        print("Exiting program. Goodbye!")
        break

    else:
        print("Invalid choice! Please enter a number from 1 to 5.")

    Behavior worth knowing

    Small details that show up when you use it.

    • Overwrite starts with a blank line. Option 3 under Update writes a newline before your text, and its prompt says "appended".
    • Other numbers at the Update menu do nothing. Anything besides 1, 2 or 3 returns to the main menu without a message.
    • Letters instead of a number show a Python error. The program catches it and prints the error text after "An error has occured".
    • Delete is immediate. The file is removed as soon as the name matches.

    Read it, run it, change it.

    The program is a single file with no dependencies. Clone the repo, run it in an empty folder, then try fixing one of the quirks listed above.
